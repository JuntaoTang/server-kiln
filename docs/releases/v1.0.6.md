## ServerKiln 1.0.6

- "Training finished" notifications reach the iPhone again. They are now sent as the same iCloud record type as "training started", which iCloud delivers reliably.
- The Mac follows the iPhone's notification switches (training started, training finished, offline / recovered) before it sends anything.
- A Mac switched off in the iPhone's Sync sources no longer sends notifications; another Mac sends them instead. Settings → iPhone shows when this Mac is switched off.
- New installs identify the Mac by its hardware, so reinstalling the app no longer adds a second copy of this Mac on the iPhone. A Mac removed on the iPhone shows up again with its servers once it reports.
- Shared models for servers added directly on the iPhone (iPhone app 1.0.6).

Update every Mac that runs ServerKiln: an older Mac can still send "training finished" the old way, which the iPhone does not receive.

**macOS 14+ · Universal (Apple Silicon + Intel) · Developer ID signed · Apple notarized**

Install from the update prompt in ServerKiln 1.0.3 or later, or download the DMG below.

Downloads: DMG (recommended), ZIP, appcast.xml (updater feed), SHA256SUMS.
